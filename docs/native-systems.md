# Native systems work

## Niyah.Engine
https://github.com/Grar00t/Niyah.Engine

Native C11 autoregressive model runtime and training engine with tokenizer, Transformer execution, backward gradients, AdamW, checkpoint/resume, evaluation, KV-cache decode and sampling under one canonical model layout. Broad conversational and reasoning quality remain explicitly unestablished.

## Casper / NIYAH
https://github.com/Grar00t/casper

C11 neural/runtime and symbolic-reasoning codebase with rational constraints, deterministic rules, SHA-256 integrity receipts, training paths and native binary format. Its documentation separates integrity from factual truth.

## Opcode Orchestra
https://github.com/Grar00t/opcode-orchestra

Assembly-first x86 multimedia laboratory using NASM and direct OPL register I/O, with reproducible build and verification boundaries. Included as systems-engineering evidence, not as an ALLaM quality claim.
